# Decisions

- 2026-10-19: Use a pure Python evaluation core and native Streamlit UI. No services,
  keys, live tool execution, model judges or databases are needed.
- 2026-10-19: Use occurrence-based name pairing, exact typed JSON arguments and
  explicit category weights. Document edge cases instead of hiding heuristics.
- 2026-10-19: Bundle only fictional scenarios and label every profile simulated.
  Determinism means stable reports for the same inputs, not evidence of intelligence.
- 2026-10-19: Use a scoped implementation delegate and one review delegate under
  the inherited operating guide. Delegation is development-only; the product has
  no agent orchestration.
- 2026-10-19: Focused review found mutable report evidence and missing source-release
  assets. Add defensive copies, two failing-then-passing regression tests and an
  explicit source manifest. Keep direct API collections mutable for simplicity;
  evaluation revalidates inputs and captures its own evidence snapshot.
